# World War Kaiju: playtest builds

Prototype builds of **World War Kaiju**, a game where you start as a small snake and eat your way up to a city-wrecking kaiju.

**[Download the latest Mac build](https://github.com/phillryu/kaiju-builds/releases/latest)**

## Install (Mac)
1. Unzip, then drag **Kaiju Game.app** into **Applications**.
2. Open Terminal and run:
   ```
   xattr -dr com.apple.quarantine "/Applications/Kaiju Game.app"
   ```
3. Open it from Applications. A PlayStation or Xbox controller is best; keyboard and mouse work too.

The build isn't notarized, so step 2 is needed; without it the app can bounce in the Dock forever. Controls are in `READ ME FIRST.txt` inside the zip.
